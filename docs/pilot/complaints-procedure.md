# Handling a report

Residents send reports from the Help screen or from a listing ("Report a problem with this listing"). Reports are anonymous: there is no way to reply, so the action is always on the listing or the collector.

## Every working day

Open the admin screen → **Open reports**. Oldest first. Aim to close each within three working days.

| The report says | Do | Then |
|---|---|---|
| **Wrong details** (number, area, vehicle) | Call the collector. Ask them to correct the listing in the app; the change comes back to the review queue | **Resolve**, noting what was corrected |
| **Did not turn up, overcharged, rude** | Call the collector and hear their side. First time: explain what is expected. Note it | **Resolve** with a note. Three such reports in a month: **Suspend** with the reason |
| **Safety** (dangerous driving, dumping or burning waste, threats, harm to an animal) | **Suspend first**, the same day, with the reason. Then call the collector. If a crime may have been committed, tell the resident-facing contact or the police; SetSetal is not an investigator | **Resolve** once decided. Reinstate only with a reason on record |
| **Accessibility** or a problem with the app | Pass to the developer with the wording of the report | **Resolve** when fixed, or note why not |
| **A request** ("add my area") | Note the area for recruitment; compare with "Searches with no results" | **Resolve** |
| **Spam, or nothing to act on** | — | **Dismiss**, with a short note |

## Rules

- **Write a note every time.** It is the only record of what was done, and it appears in Recent decisions.
- **A reason is required** to suspend or reinstate, and the collector reads it exactly as written. Write it as you would say it to them.
- **Never copy a resident's name, number or address into a note,** even if they put it in the report.
- **A wrong decision can be undone:** closed reports have "Reopen this report"; suspended and rejected listings have "Reinstate" and "Approve".
- If the admin knows the collector personally, another admin decides.
