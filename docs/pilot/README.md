## What to watch each week

Open the admin screen (`/#/admin`) and look at **Activity**:

- **Searches with no results** shows where residents look and find nobody. Recruit collectors there next.
- **Contact taps by listing** shows which listings residents use. A listing with many taps and several reports needs a call.
- **Feedback sent** against **Open reports**: nothing should wait more than three working days.

Phase 3 is complete when there is real contact traffic and at least one real report has been resolved through the admin screen.
