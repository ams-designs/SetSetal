# Phase 3: Controlled pilot (~4–6 weeks)

**Goal:** residents in the pilot areas reach real collectors, and the complaint process has handled real reports.
**Blocked by:** the meaning of "verified" (D2) and decision D4 in [decisions.md](decisions.md).

## Tasks

- [x] Choose the pilot area: Brikama (D3, 26 Oct 2026).
- [ ] Onboard 10–20 real collectors **in person**, including cart and tricycle operators, and record the verification check described in D2.
  - [x] Checklist written: [../pilot/onboarding-checklist.md](../pilot/onboarding-checklist.md). Until D2 defines "verified", the admin records what they checked in the approval reason.
  - [ ] Do it (owner and team).
- [ ] Distribute the app as an installable PWA through a link and QR posters, with no app store yet.
  - [x] Poster with QR code: [../pilot/poster.svg](../pilot/poster.svg), regenerated by `npm run poster -- <address>`.
  - [ ] Print and put up, once the address is final (question Q9).
- [x] Privacy-respecting analytics (Plausible or Umami, with no cookies) tracking these events. Built as anonymous counts in SetSetal's own database instead of a third-party service (question Q12): no cookies, no resident data, Do Not Track respected, shown on the admin screen under Activity.
  - [x] `search_no_results` (area, vehicle, waste)
  - [x] `contact_tap` (call or WhatsApp; the collector ID is fine, the resident's identity is not)
  - [x] `report_submitted` (type)
  - [x] `listing_marked_wrong`
- [ ] Write a privacy notice and a data-retention policy, and **have a Gambian legal adviser check them** before onboarding.
  - [x] Drafts: [../legal/privacy-notice.md](../legal/privacy-notice.md) and [../legal/data-retention.md](../legal/data-retention.md); the plain-language version is the app's Privacy screen. Retention is enforced by a nightly clean-up, and collectors can delete their account.
  - [ ] Name the data owner (D4) and have the adviser check them (owner).
- [ ] Run the complaint-handling procedure on real reports, and log what goes wrong.
  - [x] Procedure written: [../pilot/complaints-procedure.md](../pilot/complaints-procedure.md).
  - [ ] Run it on real reports.
- [ ] Test the English wording with real users. Wolof and Mandinka come after the pilot (D3).
  - [x] Test script: [../pilot/wording-test.md](../pilot/wording-test.md).
  - [ ] Run it.

## Exit criterion

There is real contact traffic in the pilot areas, and at least one real report has been resolved through the admin flow.
